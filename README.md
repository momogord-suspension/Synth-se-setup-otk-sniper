# KARTSET — Réglages Mini 60

Application web statique de réglage karting.

## Publication GitHub Pages

1. Ajouter tous les fichiers de cette archive à la racine du dépôt.
2. Dans Settings → Pages, sélectionner Deploy from a branch, branche `main`, dossier `/ (root)`.
3. Ouvrir l’adresse GitHub Pages en HTTPS dans Chrome Android.
4. Dans Chrome, menu ⋮ → Installer l’application.

Le manifeste et les icônes sont configurés pour fonctionner dans un dépôt GitHub Pages situé dans un sous-dossier.

## Fichiers importants

- `index.html` : application KARTSET.
- `manifest.webmanifest` : nom, mode d’affichage et identité de l’application.
- `icon-192.png` et `icon-512.png` : icônes Android.
- `favicon.svg` : icône du navigateur.
- `.nojekyll` : désactive le traitement Jekyll.

Les fiches restent stockées localement dans le navigateur/appareil. Exporter régulièrement une sauvegarde JSON depuis l’application.
